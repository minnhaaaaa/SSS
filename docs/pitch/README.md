# Pitch deck

`SSS-pitch-deck.pptx` is the editable nine slide judge deck. `SSS-pitch-deck.pdf` is the portable
recording/submission copy. The story leads with the agent block and treats Radar as evidence.

The deck uses only repository facts and native editable text/diagram objects. It includes no stock
media or third party visual assets; the repository MIT license therefore covers the authored deck.
Exasol product names remain trademarks of their owner and Exasol software is not redistributed.

To rebuild with the Codex bundled presentation runtime, set the skill and runtime paths described by
the presentation skill, make `@oai/artifact-tool` resolvable for `scripts/build_pitch_deck.mjs`, then
run the script with the bundled Node executable. Render every slide and inspect it before replacing
the committed outputs. The repository also includes the final demo video linked from the root README.
